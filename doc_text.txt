Studio 的普及，使用者在日常工作中累積大量 AI 對話記錄。然而，原生介面缺乏進階的對話管理、導覽與組織工具，造成使用效率低落。本計畫旨在開發一套 Chrome 瀏覽器插件，為 Gemini 及 AI Studio 使用者提供全方位的增強功能，大幅提升生產力與使用體驗。 1.2 專案目標 提供視覺化時間軸導覽，讓使用者快速定位任意對話節點 建立智慧資料夾系統，支援拖放式對話分類管理 整合提示詞庫（Prompt Vault），儲存與重複使用常用提示詞 支援多格式聊天記錄匯出（JSON、Markdown、PDF） 提供介面客製化功能，包含字體大小、視窗寬度、側邊欄調整 確保所有資料本地儲存，無外部伺服器傳輸，保護隱私 支援 Chrome、Edge、Firefox、Safari 等主流瀏覽器 1.3 產品定位 本插件定位為 Google Gemini 與 AI Studio 的全能增強套件，免費開源，主要目標用戶為： 專業使用者：每日頻繁使用 Gemini 進行工作輔助的知識工作者 研究人員：需要整理大量 AI 對話與深度研究的學術或商業研究者 開發者：使用 AI Studio 進行提示詞工程的軟體開發者 一般用戶：希望更有效率管理 AI 對話記錄的普通用戶 1.4 競品分析 功能 本插件 Gemini 原生 其他插件 時間軸導覽 完整支援 無 部分支援 資料夾分類 視覺化呈現對話中每則訊息的節點，讓使用者不需捲動即可快速跳轉至任意位置。 以可點擊節點形式顯示所有訊息 滑鼠懸停時即時預覽訊息內容 長按節點可標記星號（Star）重要訊息 星號狀態跨分頁同步 時間軸自動跟隨目前閱讀位置滾動 支援依日期跳轉，快速回顧歷史對話 對話分支（Fork）：從任意節點開啟新的對話路徑 2.1.2 資料夾管理（Folder Manager） 原生資料夾系統，用於分類管理 5.1.2 核心類別與介面 類別 / 介面 說明 TimelineNode 代表單一訊息節點，含 id、type（user/ai）、timestamp、isStarred、preview 屬性 TimelineController 管理時間軸狀態，監聽 DOM 變化，同步星號狀態 TimelineRenderer 使用 Preact 渲染時間軸 UI，處理使用者互動事件 TimelineSync 跨分頁廣播星號變更，透過 chrome.runtime.sendMessage 5.1.3 主要邏輯流程 使用 MutationObserver 監聽對話 DOM 新增 每次偵測到新訊息，建立 TimelineNode 並更新時間軸 點擊節點觸發 scrollIntoView，平滑捲動至目標訊息 長按 500ms 觸發星號標記，寫入 chrome.storage.local 透過 EventBus 廣播星號變更至同域分頁 5.2 FolderModule（資料夾模組） 5.2.1 資料結構 欄位 型別 說明 id string (UUID) 唯一識別碼 name string 資料夾名稱（最長 50 字元） color string (HEX) 自訂顏色（可選） parentId string | null 父資料夾 ID，null 表示頂層 conversationIds string[]
