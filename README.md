# ChatFolio — AI Chat Enhancer

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge-orange)

**ChatFolio** 是一款專為 **Gemini**設計的瀏覽器擴充功能，旨在提升 AI 對話的管理效率與使用體驗。透過強大的組織功能與直覺的介面微調，讓您的 AI 工作流更加順暢。

## 🚀 核心功能

- **📍 時間軸導覽 (Timeline)**：快速穿梭於對話歷史中，輕鬆定位關鍵資訊。
- **📁 資料夾管理 (Folder Management)**：將混亂的對話分門別類，建立結構化的知識庫。
- **🗂 提示詞庫 (Prompt Library)**：管理、收藏並快速套用常用的提示詞，告別重複輸入。
- **📤 多格式匯出**：支援將對話一鍵匯出為 **Markdown** 或 **JSON** 格式，方便存檔與分享。
- **🎨 介面高度自定義**：
  - 調整對話框寬度與字體大小。
  - 支援深色/淺色模式切換。
- **☁️ 雲端同步**：支援透過 Google Drive 同步設定與資料（開發中/實驗性功能）。

## 🛠 安裝說明

1. 下載本專案原始碼。
2. 開啟 Chrome 瀏覽器，進入 `chrome://extensions/`。
3. 開啟右上角的「開發者模式」。
4. 點擊「載入解壓縮擴充功能」，選擇專案中的 `extension` 資料夾。

## 📖 使用指南

- **快捷鍵**：按下 `Ctrl + Shift + E` 可快速執行 Markdown 匯出。
- **側邊面板**：在 Gemini 或 AI Studio 頁面中，點擊側邊的 ChatFolio 圖示可展開功能面板。
- **設定介面**：點擊擴充功能圖示（Popup）或進入選項頁面（Options）進行進階調整。

## 📂 專案架構

- `extension/`：擴充功能核心程式碼。
  - `content/`：注入網頁的腳本與樣式，處理介面修改。
  - `background.js`：處理後台邏輯與 API 互動。
  - `popup/`：點擊圖示彈出的快速操作介面。
  - `options/`：詳細設定頁面。
- `doc_text.txt`：開發文件相關備註。
- `AI_ChatExtension_Design_Document.docx`：設計規格文件。
